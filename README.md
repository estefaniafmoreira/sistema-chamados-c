# Sistema de Chamados de Suporte (C)

Aplicação de terminal para registrar e acompanhar chamados de suporte de TI, desenvolvida em linguagem C.

## Funcionalidades
- [x] Menu interativo
- [x] Abrir chamado (solicitante, descrição, prioridade)
- [x] Listar chamados
- [x] Atualizar status (aberto, em andamento, resolvido)
- [x] Salvar e carregar dados em arquivo

## Tecnologias
- Linguagem C
- Git e GitHub

## Como compilar e executar
```
gcc main.c -o chamados
./chamados
```
